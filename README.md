## QA 통합 대시보드 — AI 체크리스트 자동 생성 · 데이터 검색 · 이슈 분석

## 1. 사용 도구 및 기술

* **언어 및 프레임워크** : Python + Streamlit
* **AI / LLM** : Ollama (로컬 AI 모델), 키워드 기반 문서 검색(BM25)
* **외부 API** : GitLab API
* **데이터 처리** : pandas, pdfplumber
* **실행 환경** : 로컬 서버 (외부 서버 없이 동작)

## 2. 프로젝트 구조

Project  
├── dashboard.py  
├── chatbot.py  
├── search.py  
├── data/  
└── .env  

| 파일명 | 역할 및 내용 |
| ------ | ------ |
| dashboard.py | 화면 구성 및 페이지 전환 처리 |
| chatbot.py | AI 챗봇 로직, GitLab 이슈 수집, 문서 검색 처리 |
| search.py | CSV 테이블 로드, 데이터 검색 · 검증, 체크리스트 생성 |
| data/ | QA 데이터 CSV 테이블 저장 폴더 |
| .env | GitLab API 토큰 및 환경 변수 설정 |

## 3. 주요 기능 및 실행 흐름

### 3-1. 체크리스트 자동 생성
```
[GitLab 이슈 번호 입력 (선택)]
    ↓
[GitLab에서 이슈 본문 · 코멘트 자동 수집]
    ↓
[추가 내용 직접 입력 (선택)]
    ↓
[AI가 QA 체크리스트 자동 작성]
    ↓
[Google Sheets에 바로 붙여넣기 가능한 형태로 복사]
```

### 3-2. AI 데이터 검증
```
[검증 조건 입력 (텍스트 or 파일 업로드: CSV · XLSX · PDF · TXT)]
    ↓
[테이블 직접 선택 or AI가 관련 테이블 자동 탐색]
    ↓
  ├─ CSV / XLSX 파일 조건
  │    실제 데이터와 행 단위로 직접 비교
  │    불일치 항목 발생 시 → AI가 원인 추가 분석
  │
  └─ 텍스트 조건
       AI가 조건을 읽고 데이터 검증 후 결과 출력
```

### 3-3. AI 챗봇
```
[모드 선택: 자유대화 / 데이터 참조]
    ↓ (데이터 참조 모드)
[테이블 or GitLab 이슈 불러오기 → 검색용으로 정리]
    ↓
[자연어 질문 입력]
    ↓
  ├─ 시간 기반 질문 ("1시간 전", "최근", "오늘" 등)
  │    GitLab 이슈 전체를 최신순으로 정렬 후 AI에 전달
  │
  └─ 일반 질문
       키워드 검색으로 관련 데이터 추출
    ↓
[AI 답변 생성 + 출처 표시]
```

### 3-4. 테이블 검색 · 뷰어
```
[검색어 입력]
    ↓
  ├─ AI 테이블 선별 ON
  │    AI가 키워드를 확장해 관련 테이블만 골라 검색
  │
  └─ AI 테이블 선별 OFF
       키워드를 직접 추출해 전체 테이블 검색
    ↓
[테이블별 결과 출력 + CSV 다운로드]
```

## 4. 결과물 검토 및 보완

### 1. 개발 중 발생한 문제 및 원인

**1-1. 시간 기반 질문 오작동**
- "1시간 전 등록된 이슈"처럼 시간 조건이 포함된 질문은 키워드 검색으로는 정확한 결과를 찾지 못하는 문제 발생
- GitLab 시간 데이터가 UTC 기준으로 저장되어 있어 AI가 현재 시각과 비교할 때 오차 발생

**1-2. GitLab 이슈 재로드 시 데이터 중복**
- GitLab 이슈를 다시 불러올 때마다 기존 데이터 위에 새 데이터가 추가되어 동일 이슈가 중복으로 검색에 반영되는 문제 발생

**1-3. 화면 새로고침마다 AI 모델을 반복 호출하는 문제**
- Streamlit은 화면이 갱신될 때마다 전체 코드를 다시 실행하므로, 매번 AI 모델 정보를 불러와 불필요한 처리 발생

### 2. 수정 · 보완한 내용 및 이유

**2-1. 시간 관련 질문 자동 감지 처리**
- "한시간", "두시간", "오늘", "최근" 등 시간 표현을 자동으로 감지해 일반 키워드 검색을 건너뜀
- GitLab 이슈 전체를 등록 시간 기준 최신순으로 정렬 후 AI에 전달
- AI에게 한국 시간(KST) 기준으로 비교하도록 명확하게 지시

**2-2. GitLab 데이터만 선택해서 삭제하는 기능 추가**
- 재로드 시 GitLab 이슈 데이터만 삭제 후 다시 불러오도록 처리
- 테이블 데이터는 그대로 유지되어 불필요한 재처리 없음

**2-3. AI 모델 및 데이터 임시 저장으로 성능 개선**
- CSV 테이블, AI 모델, 검색 데이터를 화면이 바뀌어도 유지되도록 저장
- 불필요한 중복 호출을 없애 응답 속도 개선

**2-4. 데이터 검증 방식 이중 적용**
- 텍스트 조건은 AI가 직접 판단 / 파일 조건은 실제 데이터와 자동 비교로 구분
- 주관적 판단과 정확한 수치 비교를 모두 커버

### 3. 실무 관점에서 추가 가능한 케이스

**3-1. 체크리스트 관련**
- 기획서 변경 전후 버전 자동 비교 및 달라진 항목 추출
- 체크리스트 완료 여부를 GitLab 이슈에 자동으로 댓글 등록

**3-2. 챗봇 관련**
- AI가 답변할 때 참고한 데이터 항목 강조 표시
- Ollama 외 다른 AI 모델(OpenAI, Claude 등) 선택 가능하도록 확장

**3-3. 데이터 검증 관련**
- 여러 테이블 간 연결된 데이터 오류 자동 검사
- 검증 결과를 보고서로 자동 생성 후 GitLab 이슈에 첨부
